# Provenance and contributions

This repository presents one continuing project on lightweight relation-label denoising. The consolidated release was prepared on 14 November 2026 and contains a single commit. Earlier Git history is preserved separately in a local backup.

## Project development and contributions

The original NYU NLP course project was completed by **Zijun Wu, Tianchen Xie, and Tianluo Zhang**, under Professor Adam Meyers. The group jointly discussed the initial model design. Zijun proposed the linguistic scoring rules and explained their rationale in the course paper; teammates contributed to parameter tuning, experiments, and the joint project. These are historical contributions described by Zijun, not inferred from this release's commit authorship.

Source repository:

- https://github.com/LewisZZZ-Zhang/NLP_Final_Project

The rule scorer and traceable conversion logic were adapted from the team repository snapshot `d3fb2d9a6f791fa53e610f072b06de5dbb2c7415`, following the October 2026 evaluation repair and logistic-regression experiments. `src/relden/legacy_rules.py` retains the original hand-written rules. `src/relden/conversion.py` retains the corrected converter. No third-party neural model, dataset, or previous Git history is bundled here.

## Implementation and evaluation

At Zijun's request, a coding agent assisted with the experimental design, implementation, execution, testing, and preparation of this release. The model progressed from hand-weighted linguistic rules to learned logistic weights, then to relation-conditioned local lexical features and explicit clean-retention objectives. The release includes nested grouped validation, ablations, portable model exports, and a reproducibility report. The report credits the original team contributions without attributing every later implementation or experiment to all coauthors.

All numerical results in this release were regenerated by the included scripts; results from earlier evaluation protocols are not mixed into the current comparisons.

## Data and rights

ARNOR 2.0 is provided by its original authors using New York Times text. Download it from the authors' site with `scripts/download_data.py`. Raw sentences and the original corpus are excluded from this repository. Saved predictions contain hashes, labels, scores, and decisions so aggregate metrics can be audited without redistributing the articles.

The original project did not supply a license for its rule-filter code. This release preserves attribution and does not impose a new blanket license on collaborators' or third-party material. Contact the authors before reuse beyond permissions otherwise available to you. The OpenNRE code and its license from the old working tree are not included because this release does not use that code.

## What the evidence supports

- A lightweight supervised filter over hand-designed and learned local features improves the measured trade-off on the development OOF evaluation and the main diagnostic test subset.
- No pristine external holdout, downstream relation-extractor improvement, neural-model superiority, or universal clean-retention guarantee is established.
- The specialized `test_noise` diagnostic provides a counterexample to uniform superiority. It is included in the report and raw aggregate results.
